# certjay.github.io

Personal portfolio of **Miguel Jay Faustino**: Business Analyst building toward data engineering.

Live site: https://certjay.github.io

## What's here

- `index.html` is the whole site: one self-contained page (HTML, CSS and a few lines of JavaScript). No build step.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

## How to update it

1. Edit `index.html` (on GitHub: open the file, click the pencil icon).
2. Commit the change. GitHub Pages republishes in about a minute.

Typical updates:
- **New project shipped:** change its status pill from `pill plan` / `pill wip` to `pill ok` and add the repo link.
- **Learning log:** add a new `<li>` at the top of the `log` list.
- **New certificate:** copy one `cert` block in the Certifications section.
- Bump the "Last updated" date in the footer.
