Onboard Spend Pipeline

FlagshipPlanned · Jan 2027

A scheduled ETL pipeline over synthetic resort-at-sea spending data. Guest charges from different outlets are extracted, reconciled against folio totals, modeled into daily revenue tables and served to a dashboard.

Why it matters

Hospitality finance teams reconcile outlet charges by hand every night. This shows how that check becomes an automated, tested job.

Architecture

CSV + API (synthetic) → Python extract → validate → PostgreSQL → SQL models → Power BI
scheduled with Airflow · packaged with Docker
